# Development

## Scripts

| Command | What it does |
|---|---|
| `npm run dev` | Dev server with hot reload at http://localhost:5173 |
| `npm run dev -- --host` | Same, reachable from your phone on the same Wi-Fi (use the Network URL it prints) |
| `npm test` | Vitest: rules, progress/achievements, iOS parity (24 tests) |
| `npm run typecheck` | TypeScript strict check |
| `npm run build` | Typecheck + production build into `dist/` (includes the service worker) |
| `npm run preview` | Serves `dist/` at http://localhost:4173 to test offline mode and installing |
| `npm run icons` | Regenerates `public/icons/` (needs Python with `pillow` and `numpy`) |

The service worker is only generated by `build`, so test offline and install behavior with
`npm run build && npm run preview`, not with `dev`.

## Testing on a phone

- **Quick look:** `npm run dev -- --host`, then open the Network URL on the phone. Offline and install
  don't work here, because service workers need HTTPS or localhost.
- **Full PWA:** push to GitHub and use the Pages URL, or tunnel `npm run preview` through an HTTPS
  tool of your choice.

## Where to change things

| To change | Edit |
|---|---|
| Rules, scoring, Action timing | `src/model/engine.ts` (keep `GameEngine.swift` in step if the iOS app should match) |
| Achievements | `src/model/progress.ts` (`ACHIEVEMENT_INFO` and the checks in `record`) |
| Tile colors and art | `src/game/tileArt.ts` and the CSS variables at the top of `src/styles.css` |
| Sounds | `src/audio/sound.ts` |
| Copy on screens | `src/ui/*.ts` |
| App name, colors in the install manifest | `vite.config.ts` |

If you change anything in `src/model/rng.ts`, `daily.ts`, or the order of random draws in
`engine.ts`, Daily boards will no longer match the iOS app. See [PARITY.md](PARITY.md).

## Releasing

1. Bump `version` in `package.json` and `VERSION` in `src/ui/dom.ts`.
2. `npm test && npm run build`.
3. Commit and push to `main`; the workflow deploys. Players see the update banner.

## Known platform limits

| Platform | Limit |
|---|---|
| iPhone/iPad Safari | No vibration (no Vibration API). No install prompt; players use Share → Add to Home Screen, and the title screen shows a hint. Data for sites not on the Home Screen can be cleared after about a week without a visit. |
| All browsers | Sound starts only after the first tap or key press (autoplay rules). |
| Safari 16.4+ | The app asks for "ambient" audio, so it mixes with music and respects the silent switch; older versions may play through it. |
